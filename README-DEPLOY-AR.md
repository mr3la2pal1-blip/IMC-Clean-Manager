# IMC Clean Manager - Public Deployment

هذه النسخة تم تجهيزها للنشر العام كخدمة Node.js.

أهم الإصلاحات:
- استخدام PORT الذي توفره منصة الاستضافة بدل تثبيت المنفذ 3000.
- الاستماع على 0.0.0.0.
- تشغيل نسخة Production عند استخدام npm start.
- إضافة render.yaml لتسهيل النشر على Render.
- المسار /api/health جاهز لفحص الخدمة.

ملاحظة مهمة:
قاعدة البيانات SQLite محلية، لذلك هذه النسخة مناسبة للاختبار والنشر التجريبي. لا تعتمد عليها كقاعدة بيانات مستشفى إنتاجية قبل نقل البيانات إلى قاعدة بيانات سحابية دائمة.
